    def ask_ai(self):
        try:
            self.session.add_event("info", "Requesting AI completion...", "api")
            response = requests.post(
                "https://api.inceptionlabs.ai/v1/chat/completions",
                headers={
                    "Authorization": "Bearer INCEPTION_API_KEY",
                    "Content-Type": "application/json"
                },
                json={
                    "model": "mercury-2.5",
                    "reasoning_effort": "low",
                    "messages": [
                        {"role": "user", "content": "What is a diffusion model?"}
                    ]
                }
            )
            result = response.json()
            print(result)
            self.session.add_event("info", "AI completion received.", "api")
        except Exception as e:
            self.session.add_event("error", f"AI API failed: {e}", "api")

what does it do?

The added ask_ai method and button act as a direct bridge between your PySide6 desktop application and a cloud-based AI service.

When a user clicks the "Ask AI" button in the Lab tab, the application executes the following sequence:

Logs the Action: Records "Requesting AI completion..." into the application's internal event log (self.session.add_event).

Sends the Request: Sends a secure HTTP POST request (via the requests library) to the Inception Labs API.

Submits a Prompt: Passes the hardcoded question "What is a diffusion model?" to the "mercury-2.5" AI model.

Prints the Output: Waits for the AI to generate a response, parses the returned data, and prints the raw JSON dictionary directly to your system console (the terminal running main.py).

Logs the Completion: Records "AI completion received." in the app's event log.

If the network connection drops or the API key is invalid, the except block catches the failure and logs the specific error message to the session log, preventing the entire graphical interface from crashing.
