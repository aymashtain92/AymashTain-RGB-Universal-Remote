🔥 3 High Priority Fixes in aymashtain/ble/manager.py
1. BLE disconnections when idle - Keepalive
Don't just check timestamp, use asyncio.wait_for with timeout. If no command for 30s, send safe ping BC01010155 (Power ON - idempotent, no blink).

Python
try:
    frame = await asyncio.wait_for(queue.get(), timeout=30.0)
except asyncio.TimeoutError:
    if time.time() - state.last_write_ts >= 30.0:
        await self._send_raw(address, CMD_ON) # ping
2. Command spamming - Rate limiting
last_send_ts must live outside the loop in DeviceState, not reset to 0 each time. 50ms = max ∼20 commands/sec, which MR Star clones can handle.

Python
elapsed = now - state.last_send_ts
if elapsed < 0.05:
    await asyncio.sleep(0.05 - elapsed)
3. Memory leak - Cleanup
Cancel the task, drain the queue, then delete everything:

Python
async def disconnect(self, address):
    if address in self._workers:
        self._workers[address].cancel()
        try: await task
        except CancelledError: pass
        del self._workers[address]
    if address in self._queues:
        # drain
        del self._queues[address]
    del self._states[address]
    del self._clients[address]
