## 1. What this is

Windows desktop app for controlling cheap BLE LED strips using the MR Star
protocol family.

Target hardware:

- `GATT--DEMO` BLE devices
- Service: `00002022-0000-1000-8000-00805f9b34fb`
- Write characteristic: `0000fff3-0000-1000-8000-00805f9b34fb`

Known strips:

- `41:42:59:F1:C8:68`
- `41:42:43:E7:8B:F6`
- `41:42:F9:D7:45:B0`

## 5. Compile check

After replacing **any** file, run `py_compile` on it. No output = success.

Sample (the full list is in `03_TODO_USER_AND_AI.md` Section D):

```powershell
python -m py_compile .\main.py
python -m py_compile .\aymashtain\app.py
python -m py_compile .\aymashtain\ble\manager.py
python -m py_compile .\aymashtain\protocol\mrstar.py
```

**`py_compile` is not enough on its own.** It cannot catch a file whose
contents are valid Python but wrong for its role. Always also run:

```powershell
python -m pytest -q
```

after touching any `__init__.py` — that is what caught the Session 8
import collision.

## 9. How to hand off to an AI

**The bundle is flat.** No subfolders inside the ZIP. Every file sits in
one folder with a unique name; nested paths use `__` separators and every
source file starts with a `# Original Path:` header.

Short version:

1. Double-click `make_handoff.bat`.
2. A numbered zip appears in `handoff\` — `handoff_001.zip`,
   `handoff_002.zip`, and so on. Nothing is overwritten.
3. Unzip it anywhere.
4. Drop the whole unzipped folder into a fresh AI chat.
5. Paste the prompt from `AI_SYNC_PACK\02_UNIVERSAL_AI_PROMPT.md` as the
   first message.
6. Tell the AI which single file to work on next.

What the flat bundle contains:

- **`HANDOFF_README.txt`** — top of the bundle, tells the next AI where
  to start.
- **`00_PROJECT_MASTER_DOCS.md`** — merged from the old `00`, `02`, `05`,
  `07` docs.
- **`01_WORKFLOW_AND_TODO.md`** — merged from the old `01`, `03`, `04`.
- **`02_CURRENT_CHAT.md`** — the old `06`.
- Every source file (with its `# Original Path:` header).

The flat bundle exists because most AI chat platforms refuse nested
folders and DeepSeek caps uploads at 50 files. Merged docs + flat names
keep the count well below that.

Deliberately excluded from the bundle:

- `__pycache__`, `.venv`, `build\`, `dist\`, `.git`
- `.db` files (private profiles and buttons)
- Session logs, exported `events.csv` / `events.json`
- `test.txt`
- The `handoff\` folder itself

## 11. Troubleshooting

- **No devices:** phone Bluetooth off, MR Star app closed, power-cycle
  strips.
- **No reaction:** confirm FFF3 UUID, `BC0406` colour, `BC0506`
  brightness.
- **Far strip drops:** raise inter-device delay in `config.json` or the
  GUI (default `inter_device_delay_ms = 60`).
- **Pale colours:** brightness inside colour frame — check
  `protocol/mrstar.py`.
- **Camera:** install `opencv-python`, try camera index 0/1/2, calibrate
  ROI. If exposure or WB lock reports "locked" but the picture keeps
  changing, the driver is lying — check Round 3 Phase 1 for the fix.
- **Audio:** pick the right device. Look for Line In / AUX / Stereo Mix
  / VoiceMeeter.
- **Console sends 100% when Options max is 60%:** Round 3 Phase 0 clamp
  bug. Do not claim it is fixed until it is.
- **Icon missing:** confirm `assets\aymashtain.ico` exists (`paths.py`
  looks there).
- **Import errors after editing an `__init__.py`:** run
  `python -m pytest -q` immediately. `py_compile` will not catch them.
