## 1. What this is

Windows desktop app for controlling cheap BLE LED strips using the MR Star
protocol family.

Target hardware:

- `GATT--DEMO` BLE devices
- Service: `00002022-0000-1000-8000-00805f9b34fb`
- Write characteristic: `0000fff3-0000-1000-8000-00805f9b34fb`

Known strips:

- `41:42:59:F1:C8:68`
- `41:42:43:E7:8B:F6`
- `41:42:F9:D7:45:B0`

## 5. Compile check

After replacing **any** file, run `py_compile` on it. No output = success.

Sample (the full list is in `03_TODO_USER_AND_AI.md` Section D):

```powershell
python -m py_compile .\main.py
python -m py_compile .\aymashtain\app.py
python -m py_compile .\aymashtain\ble\manager.py
python -m py_compile .\aymashtain\protocol\mrstar.py
```

**`py_compile` is not enough on its own.** It cannot catch a file whose
contents are valid Python but wrong for its role. Always also run:

```powershell
python -m pytest -q
```

after touching any `__init__.py` — that is what caught the Session 8
import collision.

## 9. How to hand off to an AI

**The bundle is flat.** No subfolders inside the ZIP. Every file sits in
one folder with a unique name; nested paths use `__` separators and every
source file starts with an `# Original Path:` header.

Short version:

1. Double-click `make_handoff.bat`.
2. A numbered zip appears in `handoff\` — `handoff_001.zip`,
   `handoff_002.zip`, and so on. Nothing is overwritten.
3. Unzip it anywhere.
4. Drop the whole **unzipped folder** into a fresh AI chat.
5. Paste the prompt from the top of `00_PROJECT_MASTER_DOCS.md` as the
   first message. (Or just tell the AI to read `HANDOFF_README.txt`.)
6. Tell the AI which single file to work on next.

**Target size: 32 files.** Well under 35, so the user can still attach
screenshots under DeepSeek's 50-file upload cap.

### What the flat bundle contains

- **`HANDOFF_README.txt`** — top of the bundle, tells the next AI where
  to start.
- **`00_PROJECT_MASTER_DOCS.md`** — merged from the old `00`, `02`,
  `05`, `07` docs (project summary + universal prompt + dev readme +
  handoff guide).
- **`01_WORKFLOW_AND_TODO.md`** — merged from the old `01`, `03`, `04`
  docs (timeline + TODO + AI-errors list).
- **`02_CURRENT_CHAT.md`** — the old `06` (session log).
- **`_package_init_exports.md`** — the five tiny sub-package
  `__init__.py` files merged into one reference doc.
- Every source file (with its `# Original Path:` header), flattened.

### What is excluded

- `.gitignore`, `pyproject.toml`, `requirements.txt`, `.spec`,
  `README.md`, `CREDITS.md`, `LICENSE.txt` — not needed by the AI.
- `__pycache__`, `.venv`, `build\`, `dist\`, `.git`, `.pytest_cache`.
- `tests/`, `assets/`.
- `.db` files (private profiles and buttons).
- Session logs, exported `events.csv` / `events.json`, `test.txt`.
- The `handoff\` folder itself.
- All `AI_*` helper files (`AI_CONTEXT.md`, `AI_NOTES.md`,
  `AI_SESSIONS.md`, `AI_BRIEF.md`, `AI_BACKLOG.md`, `PROJECT.md`,
  `ai_sync.py`).

### Running the builder

```powershell
# Build the zip:
python make_handoff.py

# Or list the files only, without creating a zip:
python make_handoff.py --dry-run
```

Or double-click `make_handoff.bat`, which runs the builder, prints the
file count and the "under 35 / under 50" check, and opens the
`handoff\` folder when it's done.

### End-of-session ritual

`AI_SYNC_PACK/08_End_Chat.md` is a reusable prompt the user pastes at
the end of any AI session. It tells the AI to append a new session
section, tick/move TODO items, add a workflow entry, add new
AI-error rules if a mistake was made, and deliver the sync-pack files
one at a time. It lives only on the user's PC — **not** merged into the
bundle.

## 11. Troubleshooting

- **No devices:** phone Bluetooth off, MR Star app closed, power-cycle
  strips.
- **No reaction:** confirm FFF3 UUID, `BC0406` colour, `BC0506`
  brightness.
- **Far strip drops:** raise inter-device delay in `config.json` or the
  GUI (default `inter_device_delay_ms = 60`).
- **Pale colours:** brightness inside colour frame — check
  `protocol/mrstar.py`.
- **Camera:** install `opencv-python`, try camera index 0/1/2, calibrate
  ROI. If exposure or WB lock reports "locked" but the picture keeps
  changing, the driver is lying — check Round 3 Phase 1 for the fix.
- **Audio:** pick the right device. Look for Line In / AUX / Stereo Mix
  / VoiceMeeter.
- **Console sends 100% when Options max is 60%:** Round 3 Phase 0 clamp
  bug. Do not claim it is fixed until it is.
- **Icon missing:** confirm `assets\aymashtain.ico` exists (`paths.py`
  looks there).
- **Import errors after editing an `__init__.py`:** run
  `python -m pytest -q` immediately. `py_compile` will not catch them.
- **`make_handoff.bat` produces 80+ files:** the wrong version of
  `make_handoff.py` is on disk. Replace it with the version from
  Session 11 — it uses an explicit allowlist and produces exactly 32.
